# LSTM-AutoTrade

업비트 API로 시세를 받아 LSTM으로 다음 날 종가를 예측하고, 주문과 손절·익절을 자동으로 처리한 뒤 텔레그램으로 결과를 알리는 암호화폐 자동매매 봇입니다.

> 공개용 기본 구조입니다. 실제로 사용한 종목 선정 기준과 매수 판단 로직은 포함하지 않았으며,
> `scan_for_opportunities`와 `execute_trading_strategy`에는 동작 예시만 들어 있습니다.

## 개요

| 항목 | 내용 |
|---|---|
| 기간 | 2025.02.03 ~ 06.27 |
| 인원 | 2인 프로젝트 |
| 내 담당 | 시세 수집·주문, 텔레그램 알림, 기술적 지표 선정 |
| 성과 | 연구 내용을 1저자 논문 2편으로 정리, 그중 1편으로 2025 춘계학술대회 우수논문상 |

## 연구

| 논문 | 발표 |
|---|---|
| 빅데이터 기반 LSTM 예측 모델을 활용한 암호화폐 자동매매 시스템 연구 (1저자) | 2025 한국스마트미디어학회·한국전자거래학회 춘계학술대회 · **우수논문상** |
| 빅데이터 기반 시계열 예측을 활용한 주식 자동매매 시스템 연구 (1저자) | 2025 봄철학술대회 |

## 처리 흐름

```
시세 수집 → 후보 종목 선정 → LSTM 종가 예측 → 매수 판단 → 주문 → 손절·익절 감시 → 텔레그램 알림
```

`run_trading_cycle`이 4시간마다 아래 순서로 한 번씩 실행됩니다.

1. **이전 주문 정리** — 체결 대기 중인 주문, 손절·익절 지정가 주문, 보유 종목 상태를 동시에 확인
2. **후보 탐색** — 원화 마켓 종목 중 평가할 후보를 고름 (공개본은 예시)
3. **매매 실행** — 예측가와 지표로 매수 여부를 정하고 주문 (공개본은 예시)
4. **보유 현황 알림** — 원화 잔고와 보유 종목 평가액을 텔레그램으로 전송

## LSTM 종가 예측

| 항목 | 내용 |
|---|---|
| 입력 | 최근 60일 종가 (0~1로 정규화) |
| 데이터 | 업비트 일봉 최근 180일, 학습 80% · 검증 20% |
| 모델 | LSTM(100) → Dropout(0.3) → LSTM(100) → Dropout(0.3) → Dense(1) |
| 학습 | Adam, MSE, 10 epoch. 종목별로 모델을 저장해 다음 사이클에 이어서 학습 |
| 검증 | `backtest_lstm`으로 지난 30일을 하루씩 예측해 평균 오차(%) 계산 |
| 손실 후 | 손절한 거래 시점의 데이터로 모델을 다시 학습 (`retrain_on_loss`) |

## 주문과 손절·익절

- **매수** — 원화 잔고를 최대 보유 종목 수(5개)로 나눈 금액만큼 시장가 매수. 이미 가진 종목은 건너뜀
- **체결 확인** — 주문 뒤 최대 10초 동안 체결 여부를 확인하고, 체결되지 않으면 주문을 취소한 뒤 알림
- **손절·익절** — 체결가 기준 −5% 손절, +10% 익절 지정가 주문을 바로 걸어 둠
- **재매수 방지** — 손절한 종목은 4시간 동안 다시 사지 않음

## 기술적 지표

`ta` 라이브러리로 볼린저 밴드, RSI, MACD, EMA(9), ADX, ATR, 거래량 20일 평균을 계산합니다.

## 안정적으로 돌리기 위한 처리

| 문제 | 처리 |
|---|---|
| 업비트 API 호출 제한 | `RateLimiter`가 초당 API 30회·주문 10회를 세고, 넘으면 기다렸다가 호출 |
| 같은 요청 반복 | `cache_result`가 결과를 파일에 잠시 저장 (기본 1시간, 예측은 2시간) |
| 일시적인 오류 | `tenacity`로 최대 3번, 간격을 늘려 가며 다시 시도 |
| 파일 동시 쓰기 | 보유 종목·거래 내역 JSON을 `filelock`으로 잠그고 저장 |
| 오류 확인 | 매매·사이클·메인 루프 오류를 텔레그램으로 바로 알림 |

## 구성

| 클래스 | 역할 |
|---|---|
| `RateLimiter` | 업비트 API 호출과 주문 횟수를 초 단위로 세고, 한도를 넘으면 기다렸다가 호출 |
| `cache_result` | 같은 요청 결과를 파일에 잠시 저장해 반복 호출을 줄임, 실패 시 재시도 |
| `FileManager` | 보유 종목·거래 내역을 JSON으로 저장 (파일 잠금으로 동시 쓰기 방지) |
| `TradingHistory` | 거래 기록, 손절한 종목의 재매수 금지 목록 관리 |
| `StopLossManager` | 매수가 대비 손절(-5%)·익절(+10%) 주문 관리 |
| `MarketAnalyzer` | LSTM 모델 학습·예측, 기술적 지표 계산 |
| `TradingBot` | 계좌 동기화, 매수·매도 실행, 체결 확인, 보유 현황 알림 |

## 한계

- 예측 입력이 종가 하나뿐이라, 거래량이나 기술적 지표는 모델 입력에 들어가지 않습니다.
- 일봉 기준이라 하루 안의 급격한 변동에는 4시간 주기로만 대응합니다.

